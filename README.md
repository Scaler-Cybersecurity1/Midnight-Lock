**Scenerio**

You are the on-call incident responder for Harbourline Logistics, a
600-person freight company. At 02:07 on a Friday, ransomware is encrypting files
across the network and it hasn't stopped. You're the only one online.

**Your task -**

Work the incident through five phases — detect & analyse, contain,
eradicate & recover, notify, lessons learned. At each stage you either choose a
response or answer a question from the evidence locker (an EDR alert, a VPN/auth
log, a reported email, a file-server audit, a backup report, the ransom note).

**You must find:**

1. Which user account the attacker compromised.
2. How the attacker first got in (the entry vector).
3. The time file encryption began.
